# ◆ GameTree

**Дерево навыков в стиле игровой прокачки для того, что ты изучаешь.**
Одна большая круглая карта: проект в центре, вокруг темы, от них разделы и вопросы.
Осваиваешь раздел, открываются следующие, а изученное можно повторить.

## Что умеет

- **Один круг вместо списка.** В центре карты проект, вокруг него темы (Java Core, Java Advanced, Go, SQL…),
  у каждой свой сектор: от темы наружу расходятся разделы, а от разделов вопросы. Названия тем подписаны
  по краю круга, когда карта видна целиком.
- **Поворот к теме.** Клик по теме поворачивает круг так, что её ветка читается слева направо,
  а остальные темы уходят на второй план.
- **Цвет сложности и важные вопросы.** Текст вопроса зелёный, жёлтый, оранжевый или фиолетовый по сложности,
  красный «!» отмечает вопросы, которым нужно особое внимание. Карту можно отфильтровать по сложности или по важным.
- **Прокачка.** Раздел открывается, когда освоены все его требования. Состояния: закрыт, доступен,
  изучаю, освоен. Опыт и уровни от «Стажёра» до «Архитектора».
- **Вопросы для самопроверки.** Кружок перед вопросом отмечает «знаю» и даёт опыт.
- **Мини-карта раздела.** Двойной клик по разделу погружает внутрь: его вопросы и подтемы раскладываются
  отдельной картой в стиле XMind, ответы открываются в панели.
- **Повторение.** Карточки по изученным темам, забытое попадается чаще, есть отдельный круг только по важным.
  Через 21 день у раздела появляется золотая точка.
- **Спросить Claude.** Вопрос открывается в чате Claude с готовым промптом, на claude.ai ответ приходит прямо в карточку.
- **Правка как в XMind.** Отдельного режима редактора нет, всё прямо на карте: Tab добавляет вложенный
  элемент, Enter соседний, F2 или просто набор текста переименовывает, Delete удаляет, Alt + стрелки
  переставляют, 1–4 задают сложность, `!` отмечает важный, Ctrl + Z отменяет.
  Правый клик открывает меню действий, `?` показывает все клавиши.
- **Проекты.** Отдельные карты со своим прогрессом: System Design, новый язык, подготовка к вакансии.
- **Импорт и экспорт** проектов и прогресса в JSON, черновик проекта из XMind.
- **Без зависимостей.** Чистый JS и SVG, сборка даёт один HTML-файл.

В комплекте карта **Backend-разработчик (Java и Go)** из реальной карты к собеседованиям: 19 тем, 102 раздела и 593 вопроса.

## Запуск

Нужен Node.js 18+, больше ничего ставить не надо.

```bash
git clone https://github.com/Denis-VR/game-tree.git
cd game-tree
node scripts/build.mjs       # сборка в dist/index.html
open dist/index.html
```

Прогресс хранится в браузере. Через меню **⋯** его можно сохранить в файл и перенести на другое устройство.
Чтобы опубликовать свою копию, сделай форк и выбери в **Settings → Pages** источник **GitHub Actions**.

## Деревья с помощью Claude

Репозиторий одновременно плагин для [Claude Code](https://claude.com/claude-code) со skill `gametree-trees`:

```text
/plugin marketplace add Denis-VR/game-tree
/plugin install gametree@gametree
```

Дальше достаточно попросить: «добавь тему Kotlin после Java Advanced», «сделай карту по System Design»,
«добавь ответы к вопросам по Kafka». Claude правит JSON, проверяет данные и пересобирает сайт.

## Свои карты

```text
data/projects.json                    порядок проектов в меню
data/projects/<id>/project.json       проект: название, центр карты, порядок тем
data/projects/<id>/trees/<tree>.json  тема: разделы, требования, вопросы
```

Раскладка на карте автоматическая. Формат описан в [`skills/gametree-trees/SKILL.md`](skills/gametree-trees/SKILL.md).

```bash
node scripts/validate.mjs                                    # id, ссылки, циклы
python3 scripts/xmind_import.py map.xmind my-map "Моя карта" # XMind → проект, цвета становятся сложностью
```
